## Tech Stack

- Frontend : Vue.js
- Backend: : Node.js
- Database : My SQL
- Cloud(AWS) : LightSail

## Development

### **Frontend Dev**

#### Vue Project Setup and Running Guide

1. **Clone my project repository**

```bash
git clone https://github.com/nurdworker/acsap
cd front
```

2. **Install Dependencies and run**
   Before starting the Vue project, you need to install the required dependencies. Run the following command:

```bash
npm install
```

3. **Start the Application**

```bash
npm start
```

### **Backend Dev**

#### NodeJs and Express Setup and Running Guide

1. **Clone my project repository**

```bash
git clone https://github.com/nurdworker/acsap
cd back
```

2. **Install Dependencies and run**
   Before starting the NodeJs project, you need to install the required dependencies. Run the following command:

```bash
npm install
```

3. **Start the Application**

```bash
node server.js
```
